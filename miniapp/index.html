News Meva is a professional multi-user newsroom management system built for TV, digital, and print newsrooms. Manage tasks, teleprompter, bulletins, reporters, OTP, published stories, programs, ads, analytics, and more — all from one dashboard.

Dashboard

Real-time overview of all tasks, stages, and team activity.

17-Stage Workflow

Track stories from draft → script → footage → recording → editing → upload → published.

Multi-user roles

Admin, Reporter, Editor, Cameraman, Animator — each with tailored permissions and views.

Teleprompter

Studio-grade teleprompter with history, speed control, and mirroring.

Bulletins & Programs

How it works

Start in three steps.

1

Create a task

Tap the + button. Choose your task type — News, Breaking, Special Report, Story, Press, Ground Report, Live, or Event. Set priority.

2

Move through stages

Each task flows through the 17-stage news workflow. Submit to the next stage when done. Track progress at a glance.

3

Prompt & publish

Write scripts in the teleprompter. Set speed and font. Prompt live on studio screen. Mark as published when done.

Offline-first. No account required. Optional sync when you need it.
